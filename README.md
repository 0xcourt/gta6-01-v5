## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080
```

WASD drive/walk · Shift sprint · Space handbrake · E enter/exit car, start jobs, advance dialogue · G garage (at Farol Garage) · M missions · Q radio station · 1/2/3 crew abilities · R back on the road · Esc pause.
